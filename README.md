### 🧬 `04` // ENGINEERING STANDARDS (GIT CONVENTION)

> Konsistensi adalah fondasi dari *clean codebase*. Berikut standar *commit* yang saya terapkan:

| Prefix | Scope | Example Commit |
| :--- | :--- | :--- |
| `🚀 feat` | Fitur baru untuk pengguna | `feat: add glassmorphism authentication` |
| `🐛 fix` | Perbaikan *bug* & anomali sistem | `fix: resolve mobile viewport overflow` |
| `⚡ perf` | Optimasi kecepatan & *rendering* | `perf: implement lazy loading on assets` |
| `🎨 style` | Pembaruan UI/UX & format kode | `style: refine dark mode accent palette` |
| `📝 docs` | Pembaruan dokumentasi teknis | `docs: update API integration guide` |
